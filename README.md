# ToolStack.dev

Free online developer tools. No signup. No tracking. Works offline.

## Tools

| Tool | Description |
|------|-------------|
| 📦 JSON Formatter | Format, validate, and minify JSON data |
| 🔐 Base64 Codec | Encode and decode Base64 strings |
| 🔑 JWT Decoder | Decode and inspect JWT tokens |
| #️⃣ Hash Generator | Generate MD5, SHA-1, SHA-256, SHA-512 hashes |
| 🎨 Color Converter | Convert between HEX, RGB, HSL colors |
| 🔗 URL Encoder | Encode and decode URL strings |
| 🔍 Regex Tester | Test and debug regular expressions |
| 📝 Lorem Ipsum | Generate placeholder text |
| 🆔 UUID Generator | Generate random UUIDs (v4) |
| 🔒 Password Gen | Generate secure random passwords |
| ⏰ Timestamp | Convert Unix timestamps to dates |
| 📄 Markdown Preview | Write Markdown and see live preview |
| ⏱ Cron Parser | Parse and explain cron expressions |
| 📊 Diff Checker | Compare two texts side by side |
| 🌈 CSS Gradient | Build beautiful CSS gradients visually |

## Features

- 100% client-side - your data never leaves your browser
- Beautiful dark UI
- Keyboard shortcuts
- Mobile responsive
- No signup required

## Tech Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
